## Projets

### CleanFlow

**Nettoyer un export CSV en quelques secondes, directement dans le navigateur.**

CleanFlow détecte le séparateur, nettoie les espaces, normalise emails, téléphones et dates, signale des formats invalides, dédoublonne les lignes et exporte les données nettoyées avec un rapport de qualité.

Points clés :
- JavaScript sans framework ;
- traitement local dans le navigateur ;
- aucune donnée envoyée vers un serveur ;
- tests automatisés ;
- CI GitHub Actions ;
- déploiement GitHub Pages préparé.

➡️ Repository : [leseke/CleanFlow](https://github.com/leseke/CleanFlow)

### Chroniques

**Moteur de simulation déterministe en C#/.NET.**

Chroniques est un projet personnel de simulation complexe construit avec une approche documentation-first. Il sert de terrain de conception pour l'architecture, la modélisation métier, la persistance, les tests automatisés et l'évolution incrémentale d'un système conséquent.

Le moteur couvre notamment des systèmes de population, besoins, production, mémoire, connaissances, réputation, communautés, rumeurs et influence sociale.

➡️ Documentation : [leseke/CHRONIQUES](https://github.com/leseke/CHRONIQUES)  
➡️ Moteur : [leseke/CHRONIQUES-ENGINE](https://github.com/leseke/CHRONIQUES-ENGINE)

## Ma façon de travailler

1. comprendre le problème réel ;
2. identifier ce qui peut être automatisé ;
3. proposer un périmètre clair ;
4. développer rapidement une première version ;
5. tester le résultat ;
6. corriger et documenter ;
7. livrer un outil maintenable.

J'utilise l'assistance IA comme accélérateur de développement lorsque c'est pertinent, tout en gardant la responsabilité du cadrage, de la validation, des tests et du résultat livré.
