## Working method

1. understand the real problem;
2. identify what should be automated;
3. define a bounded scope;
4. build a first working version;
5. test and validate the result;
6. document the workflow;
7. deliver something maintainable.

I use AI-assisted development when it is useful, while keeping responsibility for requirements, architecture, review, testing and final validation.
